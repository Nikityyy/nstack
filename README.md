# nstack

## Setup in T3 Code

Paste this into a T3 Code agent on the environment you want to set up.

```text
Install nstack from https://github.com/Nikityyy/nstack for every enabled provider and account in this T3 Code environment. Follow INSTALL.md. Find the configured profile paths yourself, use one shared checkout, and verify which accounts picked up the skills and working rules.
```

One install serves every account on that machine. Run the same request in each linked environment that runs its own agents.

### Updates

Ask a T3 agent to **update my nstack installation**. It can refresh the shared checkout and pick up new skills or accounts. If you enable **Automatically pull** for the nstack project, edits to existing linked skills arrive with the checkout. Use **Restart agent session** for a chat that already loaded older instructions.
